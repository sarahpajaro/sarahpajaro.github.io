DATA COLLECTION

Earnings Call Logs

From financial conversations to structured data.

Instructions & outcomesCode

01 / THE TASK

Instructions

Collect earnings call transcripts across ten listing pages, separate prepared remarks from Q&A, and organize both full calls and individual speaker turns into two dataframes.

02 / THE PROCESS

Running the notebook

An internet connection, requests, BeautifulSoup, pandas, an Excel writer, and a writable output folder. Update the Google Drive paths before running.

Open the original notebook in Jupyter or Google Colab. Review the file paths and dependencies, then run the cells in order. External datasets and Google Drive files referenced in the notebook are not included in this portfolio.

Download original notebook ↓

03 / THE RESULTS

Recorded outcomes

The saved run collected 20 links on each of ten pages. Preview tables show company names, call dates, transcript text, and speaker turns labeled Prepared or QA. The code exports both dataframes to Excel.

Summarized from the uploaded notebook and its saved outputs. Results have not been rerun for this website.
