MACHINE LEARNING

Earnings Call Classifier

Distinguishing prepared remarks from Q&A with language.

Instructions & outcomesCode

01 / THE TASK

Instructions

Build a Naive Bayes text classifier that accepts a sentence, predicts Prepared Remarks or Q&A Response, and displays the scores in a Gradio interface.

02 / THE PROCESS

Running the notebook

The earnings-call speaker-turn dataset, pandas, math, and Gradio. Update the input path, build the word dictionaries, and run the interface cells. No held-out accuracy is recorded.

Open the original notebook in Jupyter or Google Colab. Review the file paths and dependencies, then run the cells in order. External datasets and Google Drive files referenced in the notebook are not included in this portfolio.

Download original notebook ↓

03 / THE RESULTS

Recorded outcomes

The saved dataset contains 11,401 speaker turns and a vocabulary of 44,894 words. The example “we expect strong revenue growth” is classified as Prepared Remarks, with scores of −27.43 and −30.72. The saved Gradio launch failed to create a share link; no public demo is claimed.
