TEXT MINING

Readability & Forward-Looking Language

Examining how companies communicate complexity and outlook.

Instructions & outcomesCode

01 / THE TASK

Instructions

Extend the filing dataframe with sentence counts, complex-word counts, Gunning FOG readability measures, and measures of future-oriented language.

02 / THE PROCESS

Running the notebook

The 10-K files, sentiment dictionaries, a CMU pronunciation dictionary, NLTK with punkt_tab data, syllables, pandas, and BeautifulSoup. Update all local paths.

Open the original notebook in Jupyter or Google Colab. Review the file paths and dependencies, then run the cells in order. External datasets and Google Drive files referenced in the notebook are not included in this portfolio.
