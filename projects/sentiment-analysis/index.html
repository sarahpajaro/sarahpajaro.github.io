TEXT MINING

Financial Sentiment Analysis

Measuring the language inside annual reports.

Instructions & outcomesCode

01 / THE TASK

Instructions

Process downloaded 10-K files and use positive, negative, and litigious word dictionaries to create document-level language measures.

02 / THE PROCESS

Running the notebook

The downloaded 10-K text files, the three word dictionaries, pandas, and BeautifulSoup. Update the dictionary and filing-folder paths before running.

Open the original notebook in Jupyter or Google Colab. Review the file paths and dependencies, then run the cells in order. External datasets and Google Drive files referenced in the notebook are not included in this portfolio.

Download original notebook ↓

Recorded outcomes

Saved dataframe output shows filing names, word counts, and dictionary-based sentiment measures. These are word-frequency measures rather than a validated prediction of company performance.
